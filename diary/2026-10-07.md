## One-sided and two-sided p-values

A p-value is the probability, if the null hypothesis is true,
of a result at least as extreme as the one observed.
One-sided and two-sided differ only in which results count as "at least as extreme",
and that set has to be fixed before the data are seen.

- **One-sided:** the question names a direction before the experiment
  ("the coin favors heads", "anti-PD-L1 shrinks tumors").
  Only results as far or farther in that direction count.
  Coin, 9 heads in 10 flips: the set is {9, 10} heads, 11/1024.
  Lean mice: shuffles whose difference is at least the observed 373 mm^3, 2/252.
- **Two-sided:** a result in either direction counts against the null hypothesis
  ("the coin is unfair", "the drug changes tumor size").
  Equally extreme results on the other side count too.
  Coin: {0, 1, 9, 10} heads, 22/1024, the same set as Q1.
  Lean mice: differences of at least 373 mm^3 in either direction, 4/252.
- **Why the direction comes first.**
  Choosing the side after seeing which way the data went halves the p-value for nothing.
  A test run that way rejects a true null hypothesis about twice as often as its stated alpha:
  one-sided p <= 0.05 on whichever side the data fell is the same event as two-sided p <= 0.10.
- **Why exactly double in both examples.**
  Both null distributions are symmetric.
  A fair coin gives k heads exactly as often as k tails.
  With two groups of five, swapping the groups flips the sign of the difference,
  so every split has a mirror image.
- **When it is not double.**
  If the null distribution is lopsided,
  as with a null probability other than 1/2 or a shuffle test with unequal group sizes,
  the other side has no mirror image, and "equally extreme" needs a definition.
  Three are in common use, and they disagree.
  Example: 10 cells, the null hypothesis that each is a T cell with probability 0.3
  (expected count 3), and 0 T cells observed.
  One-sided (too few): P(0) = 0.7^10, about 0.028.
  - Double the smaller one-sided p-value: 0.056.
    `scipy.stats.permutation_test` does this.
  - Count results at least as far from the expected count as the observed one, |k - 3| >= 3:
    the set {0, 6, 7, 8, 9, 10}, 0.076.
    Our notebooks' `np.abs(diffs) >= abs(observed)` does this,
    because the expected difference under shuffling is 0.
  - Count results no more probable than the observed one, P(k) <= P(0):
    the set {0, 7, 8, 9, 10}, 0.039.
    `scipy.stats.binomtest` does this.

  At alpha = 0.05 only the third rejects.
  (Computed with scipy 1.18.1; the sums are binomial probabilities with n = 10 and p = 0.3.)
- The notebooks so far use only symmetric cases, where two-sided is exactly double one-sided.
  The confusion has a real cause:
  "two-sided" names one idea, "either direction",
  but for a lopsided null distribution it can mean any of three different sets of outcomes.
