Day 2 morning: the coin worksheet (paper and pencil), then notebook 3 (shuffling).

## What worked

## Student questions

- The students did not know the definition of a p-value at all.

## What did not go as well

- One-sided and two-sided p-values are confusing, even to me.
- Notebook 3 has too much text: students took a lot of time reading.
- One student was just reading one of the textbooks.
- Students struggled a lot to write `(diffs >= observed).mean()`.
  Comparing a whole array with one number at once (broadcasting) is not engraved yet.

## Follow-up

- Define the p-value after the hands-on part.
  The worksheet key (`worksheets/coin_test.tex`, "At the board after Q6") names it only at the board,
  and notebook 3 ("A p-value counts the shuffles that do as well") assumes that definition was given:
  "This fraction is the p-value from the board."
- Notebook 4 asks for "the exact two-sided p-value this morning" for the lean mice,
  but notebook 3 gives only the exact one-sided value, 2/252 (about 0.008);
  for two-sided it gives only "about 0.016" from sampled shuffles.
  The exact two-sided value is 4/252 (about 0.016).
  The coin values are 11/1024 one-sided and 22/1024 two-sided.
- In both examples the two-sided p-value is exactly double the one-sided one,
  because the null distribution is symmetric (a fair coin; two groups of five).
  That stops being true when the null distribution is lopsided, as with unequal group sizes.
  Then three common definitions disagree:
  doubling the smaller tail,
  counting results at least as far from the expected value,
  and counting results no more probable than the observed one.
  That is one source of the confusion. The notebooks so far use only the symmetric case.

## For next year

- Cut notebook 3's text.
  Not counting the collapsed answers, it has 1774 words of text for 11 code cells,
  about 160 words per code cell;
  notebooks 1 and 2 have about 1575 words each, for 17 and 14 code cells (90 and 115 per cell).
- Let students write the comparison move before notebook 3 asks for it.
  Notebook 1 shows `rolls == 3` against a fixed number, then `.sum()` and `.sum() / N`;
  `.mean()` of a comparison never appears there.
  Notebook 2 has `(means_4 >= 0.75).mean()`, but as given code that students only run.
  So notebook 3 is the first time students write the move themselves,
  and the first time the number on the right is a variable (`observed`) rather than a literal,
  yet it calls it "notebook 1's compare-then-average move".
  Options: a write-it-yourself step in notebook 2,
  or splitting notebook 3's cell into print `diffs >= observed`, then `.sum()`, then `.mean()`.

# Day 2 afternoon

Learning with AI ("Statistics and AI driver's license"), taught by Hyungju:
ways to use AI to learn, reading code with AI (notebook 4),
Type I and Type II errors and power (notebook 5),
and AI-assisted data analysis with real data (notebook 6).

## What worked

- Introducing ways to use AI to learn was okay.
- Teaching Type I and Type II errors, power, and effect size was successful.

## What did not go as well

- The ways to use AI to learn would have been more effective with prepared examples.
- The direction for reading code with AI was not clear.
- I spent most of the time explaining Type I and Type II errors, power, and effect size.
  The use of AI while learning these was not clearly demonstrated,
  although the point of the session was that students can have an AI TA or tutor.
- There was no time for the data analysis.
  I could only tell students which steps can use AI (preprocessing, figures)
  and what to be careful about.

## Follow-up

- Prepare premade examples for the ways to use AI to learn:
  the same question asked as a plain request and in tutor mode, with both transcripts,
  so students see the difference before trying it.
- For reading code, prepare a clear example of each prompt or skill applied to one piece of code
  (review without rewriting, three levels of explanation, an HTML page that animates the code, quiz me),
  with the output it produced.
- For Type I and Type II errors, choose one of two formats instead of explaining at the board:
  more hands-on, with students exploring and visualizing the concepts themselves,
  or me demonstrating the AI tutor live on the same concepts.
- Leave enough time for the AI-assisted data analysis (notebook 6),
  or move it to its own session.
